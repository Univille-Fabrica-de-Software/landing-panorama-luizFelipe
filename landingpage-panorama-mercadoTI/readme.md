# Landing Page - Panorama do Mercado de Tecnologia

## Nome do Acadêmico:

Luiz Felipe da Silva

## Objetivo: 

Apresentar um resumo das vagas locais e nacionais, destacando as principais tecnologias e competências exigidas pelo mercado de trabalho na área de Tecnologia, para aproximar a necessidade do mercado com os acadêmicos da área.

## Tecnologias utilizadas

- HTML5
- CSS3

## Principais percepções

Durante a pesquisa foi possível observar que o mercado de tecnologia busca profissionais com conhecimentos em linguagens e ferramentas como Java, Spring Boot, SQL e Git, sendo as exigências que mais se repetiram. Além das competências técnicas, habilidades comportamentais como comunicação, trabalho em equipe, organização, responsabilidade, autonomia e resolução de problemas são frequentemente destacadas e até requeridas nas vagas analisadas.
